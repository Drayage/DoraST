🏝 무인도 탈출
Island Escape · v0.2
2025년 봄, 태평양 항해 도중 폭풍을 만났다 거대한 파도가 배를 덮쳤고, 탈출 보트조차 소용없었다.
정신을 차리자 낯선 모래사장 위에 혼자 쓰러져 있었다.

사방은 바다. 섬은 작고, 문명의 흔적은 없다.
하지만 포기할 수 없다. 어딘가에 탈출의 실마리가 있을 것이다.

탐색하고 · 수집하고 · 제작하라
탈출도 100%를 달성하면 구조된다 · DOOM이 100%에 달하면 최후가 찾아온다
📋 게임 규칙 & 핵심 개념
🎉 승리 — 탈출도 100% 달성 시 구조됨.
💀 패배 — ❤️체력 또는 🧠정신력이 0 / ☠️DOOM 100% 도달.

⚙️ 기본 흐름
타일 클릭 → 이동(1칸=AP1) → 🔍탐색(AP2) → 이벤트 판정 → 자원 획득
🏕️캠프 건설(AP8) → 🔨제작소에서 도구 제작 → 🎒수집(AP3)으로 자원 확보 → 탈출도 ↑

🃏 카드 판정
탐색·전투 시 덱 맨 위 카드 태그(자원/도구)로 성공 여부 결정.
덱이 비면 버림더미를 자동으로 섞어 재활용. 취침 시에도 전체 덱 셔플.

🌙 취침
HP·정신력 회복, 허기-14·갈증-18 소모, 날씨 변경, 덱 전체 셔플.
AP4 이상 남기고 자면 이른 취침 — 회복↑·AP+2·이벤트 확률↓.
취침 이벤트 확률: 캠프 위=2~4% · 인접=5~12% · 캠프 없음=최대 60%+

🏕️ 캠프 보너스 (취침 시 발동)
🌲숲: 식량 자동생성 · 🌊해안: 물 자동생성
🪨동굴: 정신력+5 · 🏖️해변: 카드사용 드로우+1 · 🏚️폐허: AP+1

⚔️ 전투
탐색 중 적 조우 시 시작. 카드를 공격/방어에 배정 후 라운드 해결.
도망 가능(HP-8, 망토 보유 시 HP-2). 승리 시 식량+랜덤 보상.

☠️ DOOM
매일 취침 시 증가 (1~5일: +2/일, 이후 최대 +12/일). 로그에 표시됨.
HP·정신력이 낮거나 상태이상이 많을수록 취침 이벤트 확률 ↑.
화면 크기에 따라 모바일/PC 레이아웃 자동 전환

📖 도움말
🗺️ 이동 — 안개 걷힌 타일 클릭. 거리 1칸당 AP1 소모. 한 번에 여러 칸 이동 가능.
🔍 탐색 (AP2) — 새 타일 첫 방문 시 이벤트 발생. 덱 맨 위 카드 태그로 성공/실패 판정. 이미 탐색한 곳은 재탐색 불가.
🎒 수집 (AP3) — 탐색 완료 타일 + 수집 장비 보유 시 가능. 같은 곳 반복 수집 시 성공률 감소 (최소 20%).
🏕️ 캠프 건설 (AP8) — 현재 타일에 캠프 설치. 제작 가능 + 취침 이벤트 확률 대폭 감소. 지형 보너스:
🌲숲: 식량 자동생성 · 🌊해안: 물 자동생성 · 🪨동굴: 정신력+5 · 🏖️해변: 카드사용 드로우+1 · 🏚️폐허: AP+1
🔨 제작 (AP1~) — 캠프 위치에서만 사용 가능. 재료 소모해 도구·장비 제작. 뗏목 제작(AP14+재료) → 탈출도 +15~30%.
✨ 카드 사용 (AP1) — 덱에서 5장 드로우. 식량(허기+22)/물(갈증+28)/약초(HP+10) 즉시 사용. 🪢밧줄 보유 시 +1장, 🏖️해변 캠프 시 +1장.
🌙 취침 — 다음날로 이동. 허기-14·갈증-18 소모. HP·정신력 회복. 덱 전체 셔플(버림더미 포함). AP4↑ 남기고 자면 이른 취침: 회복 추가+AP+2.
취침 이벤트 확률: 캠프 위=2~4% · 캠프 인접=5~12% · 캠프 없음=20~60%+
⚔️ 전투 — 탐색 중 적 조우 시 자동 시작. 카드를 공격/방어에 배정 후 라운드 해결. 도망 가능(HP-8, 망토 보유 시 HP-2). 승리 시 식량+랜덤 보상.
🃏 덱 순환 — 카드 사용/전투 후 버림더미로 이동. 덱 소진 시 자동 재순환. 취침 시 전체 셔플. 내구도(🔋) 소진 카드는 영구 제거.
☠️ DOOM — 매일 취침 시 증가 (초반 +2/일, 6일 이후 최대 +12/일). HP·정신력 낮거나 상태이상 많을수록 취침 이벤트 확률 ↑.
