🃏 카드 판정
탐색·전투 시 덱 맨 위 카드 태그(자원/도구)로 성공 여부 결정.
덱이 비면 버림더미를 자동으로 섞어 재활용. 취침 시에도 전체 덱 셔플.

🌙 취침
HP·정신력 회복, 허기-14·갈증-18 소모, 날씨 변경, 덱 전체 셔플.
AP4 이상 남기고 자면 이른 취침 — 회복↑·AP+2·이벤트 확률↓.
취침 이벤트 확률(기본): 캠프 위 0% · 인접 3~5% · 2칸 5~10% · 원거리 10%+ · 캠프 없음 20%(이른취침)~50%(일반)

🏕️ 캠프 보너스 (취침 시 발동)
🌲숲: 식량 자동생성 · 🌊해안: 물 자동생성
🪨동굴: 정신력+3 · 🏖️해변: 카드사용 드로우+1 · 🏚️폐허: AP+1

⚔️ 전투
탐색 중 적 조우 시 시작. 카드를 공격/방어에 배정 후 라운드 해결.
도망 가능(HP-15, 망토 보유 시 HP-2). 승리 시 식량+랜덤 보상.

🌫️ DOOM (망각의 안개)
1일: 섬의 첫 숨결 +1% (+2%/일) → 6일: 첫 번째 환각 +15% (+3%/일) → 11일: 안개가 기억을 삼킨다 +25% (+4%/일) → 16일: 망각의 심연 80%
80%+: 매 취침 정신력 추가 소모 + DOOM 상승. 취침·탐색 중 🌀망각 상태이상 카드가 덱에 침투할 수 있다.
100% 도달 시 5장 복권 (처음 생존카드 4장, 이후 점점 감소).

🗺️ 이동 — 안개 걷힌 타일 클릭. 거리 1칸당 AP1 소모. 한 번에 여러 칸 이동 가능.
🔍 탐색 (AP2) — 새 타일 첫 방문 시 이벤트 발생. 덱 맨 위 카드 태그로 성공/실패 판정. 이미 탐색한 곳은 재탐색 불가.
🎒 수집 (AP3) — 탐색 완료 타일 + 수집 장비 보유 시 가능. 같은 곳 반복 수집 시 성공률 감소 (최소 20%).
🏕️ 캠프 건설 (AP8) — 현재 타일에 캠프 설치. 제작 가능 + 취침 이벤트 확률 대폭 감소. 지형 보너스:
🌲숲: 식량 자동생성 · 🌊해안: 물 자동생성 · 🪨동굴: 정신력+3 · 🏖️해변: 카드사용 드로우+1 · 🏚️폐허: AP+1
🔨 제작 (AP1~) — 캠프 위치에서만 사용 가능. 재료 소모해 도구·장비 제작. 뗏목 제작(AP2+재료) → 탈출도 +15~30%.
✨ 카드 사용 (AP1) — 덱에서 5장 드로우. 식량(허기+22)/물(갈증+28)/약초(HP+10) 즉시 사용. 🪢밧줄 +N장, 🏖️캠프 +N장.
🌙 취침 — 다음날로 이동. 허기-14·갈증-18 소모. HP 회복. 덱 전체 셔플. AP4↑ 남기고 자면 이른 취침: HP 추가 회복+AP+2.
정신력: 회복되지만 고립감으로 매일 소모(캠프 없음 -5/있음 -2). 🪨동굴 캠프(취침+3) 유지 권장.
취침 이벤트 확률(기본): 캠프 위 0% / 인접 3~5% / 2칸 5~10% / 원거리 10%+ (거리 비례 증가) / 캠프 없음 20%(이른취침)~50%(일반). 상태이상·저체력·저허기·저갈증일수록 추가 상승, 최대 80%.

👁 상황탐색: 도구 카드 비율(40%+)에 따라 아이템만 획득. 실패 시 전투 시작.
💨 도망: 허기-5 정신력-10. 전투 중 도주는 HP-15 (망토 HP-2).
